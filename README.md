# Yash Bhawar — Portfolio

Personal portfolio website showcasing projects across **Data Analytics**, **Machine Learning**, and **AI/LLM Applications**.

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, glassmorphism, animations
- **Vanilla JS** — IntersectionObserver, typing effect, smooth scroll
- **Google Fonts** — Space Grotesk + Inter

## Local Development

Just open `index.html` in your browser. No build step needed.

```bash
# Or use a local server
npx serve .
```

## Deployment

Connected to **Vercel** via GitHub for auto-deploy on push.

## Project Structure

```
portfolio/
├── index.html       # Single-page site
├── css/
│   └── style.css    # Design system & components
├── js/
│   └── main.js      # Interactions & animations
├── assets/
│   └── images/      # Screenshots & media
└── README.md
```

## Adding a New Project

Each project is a self-contained card in `index.html`. Copy an existing `.project-card` block and update the content.
