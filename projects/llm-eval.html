Enterprise-grade LLM evaluation and benchmarking platform engineered for multi-model parallel inference, real-time WebSocket token streaming, non-blocking PyTorch BERTScore/ROUGE scoring, tripartite RAG evaluation, sentence-level NLI hallucination detection, and native FastMCP agent tool integration.

💡 The Problem

Engineering teams deploying LLMs to production lack rigorous, automated benchmarking infrastructure to compare frontier models, track prompt regressions, and detect hallucinations before shipping. Manual qualitative testing is subjective, unscalable, and slow, while naive single-prompt evaluation fails to measure critical production failure modes such as semantic drift, context unfaithfulness in RAG pipelines, latency spikes, and cost-per-token efficiency.

🎯 The Solution

A self-hosted, full-stack LLM Evaluation & Benchmarking Platform. It orchestrates parallel inference across frontier models (Gemini 3.5/3.8 Flash, Groq, Qwen, Ollama) via LiteLLM with real-time WebSocket token dispatching to Next.js 15. The evaluation core executes asynchronous PyTorch BERTScore and ROUGE-L calculations, tripartite RAG scoring, sentence-level NLI hallucination detection, Gemini G-Eval rubrics, distributed Celery batch processing, and a native FastMCP server exposing tools directly to Cursor IDE and Claude Desktop.

⚡ Key Features

⚡

Multi-Model Parallel Inference

Streams responses concurrently from multiple frontier models (Gemini, Groq, Ollama) using LiteLLM with sub-millisecond WebSocket streaming over a Redis pub/sub backbone.

🧠

Non-Blocking PyTorch Scoring

Computes BERTScore F1 (bert-base-uncased / all-MiniLM) in dedicated async thread pools alongside ROUGE-L, latency tracking, token counts, and cost estimation.

🎯

Tripartite RAG Framework

Automatically evaluates retrieval quality and generation fidelity across three dimensions: Context Relevance, Faithfulness (via NLI grounding), and Answer Relevance.

🛡️

Sentence-Level NLI Hallucination Scorer

Decomposes generated answers into individual claims, verifies each claim against source context for contradictions or ungrounded facts, and applies penalizing winner weights.

🔌

Native FastMCP Server

Exposes 5 standardized Model Context Protocol tools over stdio and sse transports, enabling Cursor IDE and Claude Desktop agents to run evaluations and query model recommendations.

⚖️

LLM-as-a-Judge (G-Eval Rubrics)

Automated semantic grading powered by Gemini 3.5 Flash across 9 pre-configured domain rubrics (Code, Summarization, QA, Data Extraction, RAG) with custom weight balancing.

📦

Distributed Celery Batch Processing

Upload large CSV/JSON datasets to asynchronous Celery worker queues (eval_batch) with real-time Redis progress tracking and CSV report export.

📊

2D Semantic Embedding Visualizer

Multi-dimensional projection (Semantic MDS / UMAP) mapping prompts, references, and candidate outputs onto an interactive 2D coordinate plane with pairwise cosine similarity matrices.

📑

Print-Styled Executive Reports

Generates print-ready HTML and WeasyPrint PDF executive summaries featuring score matrices, win-rate charts, and automated model recommendation badges.

Backend & Evaluation Engines

  • backend/services/eval_runner.py — Multi-model parallel inference orchestrator with LiteLLM gateway
  • backend/services/scoring.py — Async PyTorch BERTScore F1, ROUGE-L, latency, and token cost estimators
  • backend/services/rag_eval.py — Tripartite RAG metrics (Context Relevance, Faithfulness, Answer Relevance)
  • backend/services/hallucination.py — Sentence-level NLI contradiction & claim ungroundedness scoring
  • backend/services/llm_judge.py — Gemini G-Eval rubric evaluator with weighted multi-criteria grading
  • mcp/eval_server.py — FastMCP server exposing 5 tools over stdio/sse for Cursor and Claude Desktop
  • backend/core/database.py — Async PostgreSQL engine (SQLAlchemy 2.0 + AsyncPG) with connection pooling

Frontend UI & Infrastructure

  • frontend/app/ — Next.js 15 App Router dashboard with React 19, Turbopack, and Tailwind CSS
  • frontend/components/ — Real-time WebSocket token streamers, Recharts score matrices, and 2D MDS scatter visualizer
  • backend/tasks/eval_tasks.py — Celery distributed worker tasks for asynchronous dataset benchmarking
  • backend/services/report_service.py — Jinja2 and WeasyPrint executive summary report generation
  • docker-compose.yml — Production multi-container orchestration (FastAPI, Next.js, FastMCP, Celery, Postgres, Redis)
  • backend/tests/ — Comprehensive test suite with 93%+ coverage across 120 automated tests
