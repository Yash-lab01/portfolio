AI & LLM Project

Document AI — Document Intelligence & RAG

An advanced multi-modal document intelligence platform combining TensorFlow deep learning computer vision models with Local LLM RAG vector search to parse, classify, summarize, and query complex PDF documents.

TensorFlow Local LLM ChromaDB RAG Computer Vision NLTK Streamlit Python
View on GitHub →

💡 The Problem

Organizations process thousands of unformatted PDF documents daily — contracts, medical records, financial statements, and technical manuals. Manually reading, classifying, and extracting specific information from dense multi-page documents is slow and prone to errors.

🎯 The Solution

Document AI pairs deep learning computer vision (TensorFlow) with local LLM retrieval-augmented generation (RAG). It automatically segments PDF layouts, classifies document types, extracts structured tables and text, and powers conversational Q&A over whole document libraries.

⚡ Key Features

📑

Deep Learning Document Classification

TensorFlow computer vision models automatically categorize PDFs into invoices, legal contracts, reports, and IDs.

🔍

Local LLM Vector RAG

Chunks document text and indexes embeddings into ChromaDB for instant, hallucination-free local retrieval Q&A.

🖼️

Multimodal Layout Analysis

Extracts text regions, tables, embedded images, and handwritten annotations with high precision.

📊

Automated Executive Summaries

Generates multi-bullet executive summaries and key takeaway highlights for long research papers and reports.

🛠️ Tech Stack & Technologies

TensorFlow & Keras

Deep learning vision architecture for page segmentation and document layout classification.

Local LLM & ChromaDB

Offline semantic vector store and local language model runner for private document Q&A.

NLTK & PyPDF

Natural language preprocessing, tokenization, text cleaning, and PDF page parsing.

Streamlit UI

Interactive web dashboard with document upload drag-and-drop, PDF viewer, and live chat.
