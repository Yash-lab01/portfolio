Recruiter AI — Candidate Intelligence Agent

Built for the Redrob Data & AI Challenge. An AI candidate scoring and ranking system that parses job descriptions, analyzes multi-dimensional candidate signals, and ranks applicants with explainable skill match scores.

LLM Ranking AI Agent Semantic Search JSON Schema Python
View on GitHub →

💡 The Problem

Recruiters review hundreds of candidate profiles for open roles, leading to screening fatigue, missed top talent, and biased keyword matching that fails to understand true candidate skills and experience context.

🎯 The Solution

Recruiter AI automates resume and profile evaluation using structured LLM reasoning and signal-based scoring algorithms. It parses complex job descriptions, extracts candidate signal vectors, and generates a ranked candidate shortlist with explainable matching metrics.

⚡ Key Features

🎯

Multi-Signal Candidate Scoring

Evaluates technical skills, domain experience, education relevance, and career progression signals.

🧠

Job Description Parsing

Extracts required vs optional qualifications, seniorities, and core tech stacks into structured Pydantic schemas.

📊

Explainable Rank & Match Scores

Provides transparent percentage match scores and breakdown reasoning for why candidates were recommended.

⚡

High-Speed JSONL Batch Pipeline

Processes thousands of candidate JSONL records in minutes with lightweight CPU-optimized execution.

🛠️ Tech Stack & Technologies

LLM & Semantic Embeddings

Natural language candidate profile embedding models and zero-shot ranking prompts.

Pydantic & JSON Schema

Strict schema validation for job requirements and candidate signal extraction.

Python Data Engine

Custom scoring algorithms, NumPy matrix algebra, and JSONL batch processing.
