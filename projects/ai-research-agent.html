AI Research OS — Autonomous Research Assistant

An end-to-end literature research platform built with LangGraph, Next.js 15, and Qdrant. Discovers arXiv preprints, parses multi-column PDFs with Docling, captions diagrams using local vision models, and generates verified literature reviews with paragraph-level clickable citations.

View on GitHub →

📚 01 · Main Home & Paper Hub

💡 The Problem

Researchers face an overwhelming influx of new papers weekly. Standard chat models struggle with two-column academic layouts, mishandle mathematical formulas, cannot interpret embedded architecture diagrams, and frequently hallucinate paper citations.

🎯 The Solution

AI Research OS coordinates a specialized 4-agent LangGraph pipeline (Planner, Search, Reading, Writing). It parses arXiv PDFs using Docling layout analysis and Qwen2.5-VL vision models, indexes chunks in a Qdrant vector database, and streams responses with exact paragraph-level citation badges so every claim is verifiable.

⚡ Key Features

🔍

arXiv Discovery & Smart Ingest

Search arXiv with relevance/date filters, batch-queue papers in one click with duplicate prevention, and track real-time parsing pipelines.

📄

Hybrid PDF Intelligence

Combines fast-path pdfplumber with Docling layout-aware fallback, extracting formulas [MATH], markdown tables [TABLE], and figures.

🖼️

AI Figure Captioning

Extracts architecture diagrams and benchmark plots, generating detailed technical captions using local qwen2.5vl:3b vision models.

💬

Streaming Chat & Verified RAG

Server-Sent Events (SSE) streaming chat with live agent step-logs and clickable paragraph-level citation badges opening exact source context.

🤖

Dual LLM Router & Auto-Failover

Routes interactive tasks to Groq (llama-3.3-70b) for lightning speed and background bulk extraction to local Ollama (qwen2.5:7b) with automatic rate-limit failovers.

📊

Survey Generator & Gap Finder

Surfaces open research problems by cross-referencing paper limitations, builds side-by-side taxonomy matrices, and exports citations in BibTeX/APA format.

LangGraph Multi-Agent Backend

  • backend/app/agents/planner.py — Intent classifier routing to QA, comparison, or literature survey pipelines
  • backend/app/agents/reading.py — Qdrant vector retriever fetching paragraph-level context
  • backend/app/agents/writing.py — Synthesis and citation engine enforcing inline verification badges
  • backend/app/agents/gap_finder.py — Cross-references paper limitations to uncover unexplored research directions
  • backend/app/services/llm_factory.py — Dynamic dual router connecting Groq 70B and local Ollama instances

Frontend & Storage Subsystems

  • frontend/src/ — Next.js 15 App Router interface with responsive glassmorphic dark theme and audio voice research mode
  • backend/app/services/pdf_parser.py — Layout extraction engine integrating pdfplumber, Docling, and vision captioning
  • backend/app/services/vector_store.py — Persistent Qdrant vector database with semantic similarity search
  • backend/app/main.py — FastAPI server providing SSE streaming endpoints and BibTeX/CSV export APIs
