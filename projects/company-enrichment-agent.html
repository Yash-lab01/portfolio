CompanyLens — AI Web Scraper & Intelligence Agent

Enterprise-grade AI company enrichment pipeline and prospect intelligence agent built for the AI & Automation Developer Hackathon. Crawls websites, extracts verified contact info, and generates deep business insights.

Gemini 2.5 AI Agent FastAPI Cloudscraper BeautifulSoup SQLite Python
View on GitHub →

💡 The Problem

Sales, business development, and market analysis teams waste countless hours manually visiting target company websites, copying contact information, hunting through sitemaps, and trying to digest complex product offerings into actionable sales insights. Standard web scrapers often break on anti-bot protections or return unstructured HTML clutter.

🎯 The Solution

CompanyLens automates company prospect research end-to-end. It intelligently crawls high-value company pages using fuzzy sitemap weighting, circumvents Cloudflare anti-bot checks, extracts pre-compiled contact regex records, and feeds clean markdown text to Gemini 2.5 Flash for structured business insight synthesis.

⚡ Key Features

🕸️

Fuzzy Sitemap Router

Intelligently parses sitemap.xml and homepage links with weighted string matching to auto-prioritize target pages like About, Contact, and Solutions.

🛡️

Cloudflare Bypass Chain

Rotates user-agents dynamically and falls back to browser-spoofing cloudscraper to bypass endpoint protection layers seamlessly.

🔍

Regex-Guided Contact Extraction

Pre-harvests email addresses and phone numbers directly from raw HTML, passing candidate lists to the LLM for strict verification rather than generation.

🧠

Gemini Reasoning Fallback Chain

Configured with reasoning token budgets on gemini-2.5-flash with automated fallbacks to gemini-2.0-flash and gemini-2.0-flash-lite.

📊

Multi-Step Live Visual Pipeline

Real-time frontend status updates showing step-by-step progress (Scraping ➔ Analyzing ➔ Generating) with responsive visual indicators.

✨

Glassmorphism UI & Drawer Inspection

Modern dark-mode web dashboard featuring instant toggle between detailed card grid and expandable table views with slide-out detail drawers.

Backend Core

  • scraper.py — Hardened sitemap crawler with Brotli stream decoding resilience
  • enricher.py — Prompt engineering, token optimizer, and Gemini model fallback manager
  • main.py — FastAPI production web server powering REST APIs and static serving
  • database.py — SQLite storage engine maintaining historical company profile records

Frontend UI & Deployment

  • static/index.html — HTML5 single-page application structure
  • static/app.js — Dynamic API handler, multi-stage progress indicators, and modal drawers
  • static/styles.css — CSS variables, glassmorphism card components, and CSS animations
  • render.yaml — Production Render blueprint for 1-click cloud deployment
