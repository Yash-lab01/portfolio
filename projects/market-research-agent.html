AI & LLM Project

Autonomous Market Research Agent

Type a single market research question — 5 autonomous AI agents search the web, cross-verify claims, and synthesize structured executive reports with publication-quality PDF exports.

LangGraph Ollama Groq Tavily ChromaDB FastAPI Streamlit n8n Python
View on GitHub →

💡 The Problem

Conducting comprehensive market research is time-consuming and fragmented. Researchers must query multiple search engines, filter reliable sources from noise, cross-check facts, structure insights, and generate exportable reports — taking hours or days for every single query.

🎯 The Solution

An autonomous multi-agent workflow powered by LangGraph. Five specialized AI agents divide and conquer research tasks: breaking queries into sub-topics, executing real-time web searches, scraping full page content, verifying facts with local LLMs, and generating comprehensive reports complete with vector-search RAG and PDF export.

⚡ Key Features

🤖

5-Agent Collaboration

Planner, Search, Scraper, Verifier, and Summarizer agents coordinate seamlessly through a stateful LangGraph execution engine.

⚡

Hybrid Model Topology

Combines local privacy & cost efficiency (Ollama qwen2.5:7b for planning & verification) with high-speed cloud reasoning (Groq llama-3.3-70b for synthesis).

🌐

Real-time Web Scraping

Leverages Tavily search API and httpx + BeautifulSoup web scrapers to parse live source articles, news, and market data.

📚

Interactive Vector RAG

Embeds scraped research articles into ChromaDB, allowing users to ask follow-up questions directly grounded in fetched source context.

📄

ReportLab PDF Engine

Generates publication-ready, multi-page executive PDFs containing executive summaries, key trends, source citations, and visual charts.

🔄

n8n Automation Workflows

Includes pre-configured n8n workflows for Telegram trigger bots, automated daily re-research, and email PDF delivery.

→
🔍 Search & Scrape Tavily + BeautifulSoup

→

Agent Microservices

  • agents/planner.py — Decomposes complex queries into focused research sub-tasks
  • agents/search.py — Executes Tavily search queries for targeted market domains
  • agents/scraper.py — Resilient HTML content extractor stripping site clutter
  • agents/verifier.py — Evaluates source credibility and cross-verifies statistical claims
  • agents/summarizer.py — Synthesizes structured JSON reports using Groq 70B

Storage & Delivery Layer

  • graph/workflow.py — LangGraph StateGraph connecting agent state transitions
  • db/chroma_client.py — ChromaDB vector store for semantic interactive Q&A
  • report/pdf_builder.py — ReportLab engine generating styled PDF reports
  • n8n/ — Automation JSONs for Telegram triggers and automated email delivery

🛠️ Tech Stack & Technologies

LangGraph

Stateful multi-agent orchestration framework for complex cyclic AI graph workflows.

Ollama & Groq

Hybrid local LLM (qwen2.5:7b) and ultra-fast cloud LLM inference API (llama-3.3-70b).

FastAPI & Streamlit

Production REST API backend with Swagger docs and an intuitive 4-tab Streamlit dashboard.

ChromaDB & SQLite

Vector store for conversational document RAG and relational database for research history.
