Engineering Philosophy

How I Build Systems That Work in the Real World

A practical look at production AI: why monolithic prompts fail, where local quantization matters, and how data integrity drives every model.

PRINCIPLE 01

Stateful Workflows Over Monolithic Prompts

Single, giant prompts tend to drift, hallucinate details, and struggle with arithmetic. I break complex systems into stateful LangGraph agent nodes with validated Pydantic schemas. Heavy computations — like spatial clustering, geo-routing, and math formulas — run through deterministic Python solvers rather than burning AI tokens.

PRINCIPLE 02

Hybrid Latency & Cost-Effective Routing

Sending every request to a 70B cloud LLM leads to high latency and ballooning API bills. I engineer multi-tier routing architectures: sub-millisecond classifiers and local quantized models (Ollama) handle straightforward tasks instantly, reserving high-parameter cloud models strictly for complex reasoning and synthesis.

PRINCIPLE 03

Verifiable Grounding & Citation Traceability

In real-world applications, unverified AI outputs are a liability. Every RAG architecture I build guarantees source grounding — linking responses to paragraph-level citation anchors, vector similarity scores, and strict schema validation so outputs can always be traced back to raw data.

FLAGSHIP SYSTEM 01 · MULTI-AGENT STATE MACHINE

WanderAI — AI Travel Planner

An autonomous multi-agent travel system built with LangGraph and Next.js 16. Resolves spatial disorientation and routing bugs in standard LLMs through K-means++ coordinate clustering, community sentiment analysis, and interactive timeline drag-and-drop editing.

Core Problem: Standard LLMs generate geographically chaotic routes (causing zig-zag transit), hallucinate closed attractions, and lack persistent state for iterative editing.
Architecture: 4-Agent LangGraph workflow (Intake, Ranker, Planner, Editor) with SQLite checkpoints and dynamic preference clarification.
Custom Engine: Log-normalized ranking formula balancing Reddit and travel blog sentiment against Google Places review volumes.
Real Data: K-means++ spatial POI clustering, live Open-Meteo forecasts, and a 4-tier zero-auth Wikipedia photography cascade.
